# open-psd-kit

[English](README.md) · [简体中文](README.zh-CN.md)

An [Agent Skill](https://agentskills.io/specification) that teaches AI agents how to read and modify Photoshop PSD / PSB files.

This repository **is** the skill folder. The directory name, GitHub repo name, and `SKILL.md` `name` field must all stay `open-psd-kit`.

## What this is

Agents should not guess PSD binary layout or call a local Photoshop install. This skill wraps [psd-tools](https://github.com/psd-tools/psd-tools) with a stable CLI for inspect, layer trees, export, property edits, and pixel-layer replace.

It is not tied to any game project.

## What you get

| Need | Command |
|------|---------|
| Size, color mode, depth, layer count | `scripts/psd_kit.py inspect FILE` |
| Layer tree with writable flags | `scripts/psd_kit.py layers FILE --tree` |
| Flattened or single-layer PNG | `scripts/psd_kit.py export FILE --out out.png` |
| Visibility / opacity / name / blend | `scripts/psd_kit.py set FILE --layer NAME --out out.psd` |
| Replace a pixel layer | `scripts/psd_kit.py replace-pixels FILE --layer NAME --image in.png --out out.psd` |
| Create a blank RGBA document | `scripts/psd_kit.py new --size 64x64 --mode RGBA --out out.psd` |
| Read-only batch scan | `scripts/psd_kit.py batch-inspect --root DIR --glob "*.psd"` |

Human summary is the default. Pass `--json` for structured UTF-8 stdout. Failures exit non-zero and explain on stderr.

Writes go to a new file unless `--in-place` is set. Batch inspect never composites.

Sample file: `assets/sample.psd` (generated by this tool).

## Install

```bash
pip install -r requirements.txt
```

Clone into an agent skills directory and keep the folder name:

```bash
git clone https://github.com/MlsMoon/open-psd-kit.git ~/.agents/skills/open-psd-kit
```

## Quick start

```bash
python scripts/psd_kit.py inspect assets/sample.psd
python scripts/psd_kit.py inspect assets/sample.psd --json
python scripts/psd_kit.py layers assets/sample.psd --tree
python scripts/psd_kit.py export assets/sample.psd --out out.png
python scripts/psd_kit.py set assets/sample.psd --layer Fill --visible 0 --out hidden.psd
```

Guaranteed write scope is pixel-layer properties plus pixel replacement. Smart objects, live text, and complex styles may not round-trip. See `references/write-limits.md`.
